# 🧑‍🏫 Face Recognition Attendance System (Client-side)

A fully client-side face recognition attendance system built using **Next.js (App Router)**, **TypeScript**, and `face-api.js`. Users can register their face by uploading an image and later mark their attendance through face recognition using a webcam — all within the browser using `LocalStorage`.

---

## ✨ Features

- 🧠 Face detection and recognition using `face-api.js`
- 🎥 Real-time webcam-based recognition
- 📸 Upload photo to register your face
- 🧾 LocalStorage-based attendance logging (no backend required)
- ⚡ Fully client-side: works offline after initial load

---

## 🛠 Tech Stack

- **Next.js (App Router)**
- **TypeScript**
- `face-api.js`
- `@tensorflow/tfjs`
- HTML5 `video`, `canvas`, and `localStorage`
